# Customer Sales Data Analysis

Python-based sales data cleaning, exploratory data analysis, visualization, and machine learning.

## Project Overview
This project explores sales data and uses machine learning models to predict sales. It demonstrates data analysis, visualization, and regression model evaluation using Python.

## Objectives
- Understand and explore sales data.
- Perform exploratory data analysis (EDA).
- Visualize important patterns and trends.
- Train and compare machine learning regression models.
- Evaluate model performance using standard metrics.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Notebook
See the Jupyter Notebook (`.ipynb`) in this repository for the implementation, analysis, and model evaluation results.
